BalanceLens — Politique de confidentialité

Dernière mise à jour : 30.07.2026

English · Français

Vos données restent sur l’appareil par défaut

BalanceLens conserve revenus, dépenses et budgets dans le stockage local de votre appareil. Aucun compte n’est requis pour un usage hors ligne.

Synchronisation cloud optionnelle

Si Firebase est configuré pour votre build, l’authentification et les données synchronisées peuvent être hébergées par ce service. Sans Firebase, les données restent uniquement sur l’appareil.

Analytique et publicité

Nous n’intégrons pas de SDK publicitaire tiers. Les outils de diagnostic éventuels se limitent à des données techniques.

Résumé sécurité des données

Données collectées : catégories, montants, notes et dates que vous saisissez — stockés localement (et éventuellement dans Firebase).

Partage : par défaut, rien n’est envoyé à des réseaux publicitaires.

Suppression : effacez les données de l’app ou désinstallez-la ; gérez les données Firebase via ce service si la sync a été utilisée.

Enfants : l’application ne collecte pas sciemment de données auprès d’enfants.
